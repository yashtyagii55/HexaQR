## 📌 About The Project

**HexaQR** is a modern QR code generation and scanning platform designed to make sharing information faster, easier, and more convenient.

Create customized QR codes for different purposes, scan existing QR codes, and download your generated codes in multiple formats through a simple and user-friendly interface.

Our goal is to bring essential QR tools together in one convenient platform.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| ⚡ QR Generator | Generate QR codes quickly |
| 📱 QR Scanner | Scan QR codes using supported devices |
| 🔗 Multiple QR Types | Create QR codes for different types of information |
| 🎨 QR Customization | Customize QR code appearance |
| 📦 Bulk QR Generation | Generate multiple QR codes using CSV data |
| 📄 Multiple Export Formats | Download QR codes in PDF, PNG, and SVG |
| 👁️ Preview | Preview generated QR codes |
| 📱 Responsive Design | Access the platform across different devices |
| 🛠️ Admin Panel | Administrative management |
| 📩 Contact Form | Contact and communication support |
